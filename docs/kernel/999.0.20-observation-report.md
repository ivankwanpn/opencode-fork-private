## Remaining blockers and limitations

### HttpApi lifecycle

The exerciser now owns request cancellation and the cached handler graph explicitly. Auth probes use
an isolated workspace, a 15-second abortable request budget, and close their request signals.
`tui.control.next` is paired with an immediate response probe instead of leaving a long-poll waiter
alive. `disposeApps()` closes every cached handler before the isolated DB/global roots are removed.

- Full auth: 283 pass / 0 fail / 0 skip / 0 missing / 0 extra in 30.7 seconds, followed by normal
  process exit.
- Focused Effect: six route scenarios pass and exit: `/path`, `/api/path`, `/api/plugins/runtime`,
  `/tui/control/response`, `v2.session.input.cancel`, and `v2.session.input.promote`.
- The input cancel/promote cases verify that the same route graph exports the bound
  `SessionExecution` service used by SessionV2; no request-local or second coordinator is created.

A full Effect run remains unaccepted. One eight-shard attempt oversubscribed this Windows host; the
finished shards reported 12-18 failures each, and inspected failures were uniformly
`scenario timed out after 30s` across unrelated cheap routes. Two git-init shards also stopped making
progress and were explicitly interrupted. All processes were joined/stopped. This invalid stress run
is neither a pass nor evidence of route defects. A lower-concurrency or serial complete run remains
release evidence to collect.

### Structured UI contribution product bridge

The bridge is now implemented as declarative product descriptors rather than serialized executable
JSX/functions:

- Core owns command/panel descriptors by plugin ID, version, generation, Location group, and Scope.
- Activation requires `ui.command.register` or `ui.panel.register` before publication; duplicate IDs
  fail activation and disposal atomically removes every owned descriptor.
- Schema exposes owned descriptor information in the existing plugin runtime snapshot.
- Native Claude marketplace transport reads the process-global Kernel plugin host and
  `/api/plugins/runtime` carries the descriptors through sidecar/HTTP without a second registry.
- The App Installed Plugins views render matching command/panel badges and descriptions for both
  marketplace and direct plugins. Executable frontend/TUI modules remain product-local.

Fresh focused evidence is Core plugin host 24/0 (81 assertions), OpenCode marketplace transport 8/0
(37 assertions), and App presentation 5/0. The generated `types.ts` includes the public wire shape.
The broader generated declaration audit is still blocked because the protected `client.d.ts` has
pre-existing manifest drift and may not be modified in this batch.
