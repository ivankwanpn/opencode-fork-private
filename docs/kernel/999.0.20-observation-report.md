never replays provider work, never leaves the stale active row permanently busy after a decided
plan, and never fabricates a terminal outcome:
`session-kernel-fault-matrix.test.ts` — 14 pass.

the HttpApi exerciser (`--mode` scenarios) where both engines can be driven; the Classic-side
comparison run is listed as missing evidence below.
